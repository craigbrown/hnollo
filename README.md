# Hnollo

A mobile-first, read-only Hacker News client in the style of Apollo. Reading history, saved posts, and preferences stay on your device.

## Development

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

The static site is generated in `dist/`. Relative asset paths and hash-based navigation support GitHub Pages, including repository subpaths.
