# Hnollo

Hnollo is a mobile-first, read-only Hacker News client in the style of Apollo. It uses the Hacker News API to get data, and your browser's local storage to save your reading history. I don't collect any data.

This app is completely unofficial; it is not affiliated with the owners of Hacker News or Apollo in any way.

## Why?

I like reading HN, but it's a bit harder on mobile. The gold-standard design for reading posts with a bunch of comments attached is (was) the legendary [Apollo](https://apolloapp.io) app, and so I wanted something like that for HN.
